Общий ресурс

SMB (Server Message Block) - сетевой протокол прикладного уровня.
Предоставляет доступ к файлам, каталогам и другим ресурсам.
Новые SMB используют 445 порт, старые - 137-139

Основные операции SMB:
	1. Обнаружение и выбор общего ресурса
	2. Установление сеанса
	3. Аутенификация пользователя
	4. Открытие, чтение, закрыти и изменение файлов
	5. Создание и удаление каталогов
	6. Блокировка файлов при совместной работе
	7. Получение сведений о файлах и правах доступа

Samba - это свободный программный комплекс, реализующий SMB,
	позволяющий linux и limux подобным системам ...

smbd - daemon Samba`s (фоновая служба)

Аутентификация (кто обращается к серверу, имя пароль)
Авторизация (что разрешено пользователю)

Уровни Авториз и Аутентиф:
	1. Параметры ресурса
	2. Права в файловой системе

	Права должны сходиться в параметрах ресурса и файловой системе

Установка Samba сервера:
	1. apt update (обновление пакетов)
	2. apt install samba samba-client (2 пакета)
	3. Подготовка пользователя:
		- groupadd smbgroup (создание группы)
		- mkdir -p /srv/samba/projects (создание папки с абсолютным путём)
		- cd /srv/samba/projects
		- chown root:smbgroup /srv/samba/projects/
		- chmod 2770 /srv/samba/projects/ (770 - права на файловой системе)
		- adduser roman
		- adduser dima
		- usermod -aG smbgroup roman
		- usermod -aG smbgroup dima (для вхождения в группу)
		- smbpasswd -a roman/dima - добавление пользователя roman/dima
	Копирование конфигурации под новым именем:
		cp /etc/samba/smb.conf /etc/samba/smb.conf backup

	nano /etc/samba/smb.conf
	ip a - айпишник

	[ispp31] (каталог, в котором будет сервер)
		path = /srv/samba/projects (локальный путь к предоставляемому каталогу)
		browseable = yes (отображение в проводнике, отображаемый ресурс при просмотре списка)
		read only = no (не только читать)
		guest ok = no (позволяет смотреть записи без учётной записи)
		valid users = roman dima или @smbgroup (ограничение пользователей или групп, которым разрешён вход)
		write list = dima или @smbgroup (пользователям, которым разрешена запись)
		create mask = 770 (права на файловой системе, ограничение на файлы)
		directory mask = 770 (права на файловой системе, ограничение на создаваемые каталоги)

	testparm
	systemctl RESTAST smbd (перезапуск службы)
